카카오맵 API 키 입력

이 페이지는 카카오맵 JavaScript 키를 브라우저에만 사용하고 서버로 전송하거나 저장하지 않습니다. 새로고침하면 다시 입력해야 합니다.

키가 없거나 지도가 안 뜨나요?
  1. 카카오 디벨로퍼스에 로그인 → 내 애플리케이션 → 앱 선택
  2. "앱 키" 탭에서 JavaScript 키 복사 (REST API 키 아님)
  3. "플랫폼" 탭 → Web 플랫폼에 현재 이 페이지 주소(도메인)를 등록 — 등록 안 하면 키를 넣어도 지도가 안 뜹니다
